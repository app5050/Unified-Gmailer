プライバシーポリシー

Unified Gmailer（以下「本拡張機能」）は、ユーザー自身の複数のGmailアカウントを1つの受信箱で扱うための、個人利用向けChrome拡張機能です。最終更新日：2026年10月16日

1. アクセスする情報と利用目的

本拡張機能は、GoogleのOAuth認証を通じ、スコープ https://www.googleapis.com/auth/gmail.modify によりGmail APIへアクセスします。メールの閲覧・検索、ラベルの操作、既読/未読・スター・アーカイブ・削除、返信・転送・送信、未読件数と通知の表示のためだけに使用します。これらの機能を提供する以外の目的では使用しません。

2. データの保管

メールの内容、アカウントのメールアドレス、設定、認証情報は、ユーザーのブラウザ内（Chromeの拡張機能ストレージ）にのみ保存されます。開発者が運営するサーバーは存在せず、これらを開発者や第三者のサーバーへ送信・保存・共有することはありません。

認証情報は次のとおり保存されます。アクセストークン（有効期間は約1時間）は、ブラウザのセッション内にのみ保存され、ブラウザの終了などで消去されます。更新用トークン（リフレッシュトークン）は、再ログインなしでアクセス権を更新するために、ブラウザ内の拡張機能ストレージに保存されます。更新用トークンは、Googleの認証サーバー（oauth2.googleapis.com）へのトークン更新の要求にのみ使用します。ユーザーが設定画面に入力したOAuthクライアントシークレット（入力した場合）も、同じくブラウザ内にのみ保存され、Googleの認証サーバーへの要求にのみ使用します。

3. 外部サービスとの通信

本拡張機能は、次の場合を除き、外部と通信しません。

・Gmail API（gmail.googleapis.com）およびGoogleの認証サーバー：メールの取得・操作・送信と、ログイン・トークン更新のため。
・Google翻訳（translate.googleapis.com）：ユーザーが翻訳機能を有効にし、同意した場合に限り、翻訳するメールの文章がGoogle翻訳へ送信されます。翻訳機能を使わない限り、送信されません。
・メール内の画像：ユーザーが画像の表示を有効にした場合に限り、メールに含まれる画像が、送信元の指定するサーバーから読み込まれます。初期設定では読み込みません。

広告、行動の追跡、利用状況の分析のためにデータを収集・利用することはありません。

4. 第三者への提供

Googleから取得したデータを、第三者へ販売・提供・移転することはありません。また、人がメールを読むこと（ユーザー本人による閲覧を除く）、広告への利用、データの販売は行いません。Google APIサービスのユーザーデータの利用は、限定的使用の要件を含む Google APIサービスのユーザーデータに関するポリシー に準拠します。

5. データの削除

本拡張機能でアカウントを削除すると、Googleに対してそのアカウントへのアクセス権の取り消しを要求し（取り消しに失敗した場合は、下記の権限設定から手動で取り消せます）、そのアカウントのトークンと関連データがブラウザから消去されます。拡張機能を削除すると、ブラウザ内のすべてのデータが消去されます。また、Googleアカウントの権限設定 から、本拡張機能に与えたアクセス権をいつでも取り消せます。

6. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

Privacy Policy

Unified Gmailer (the "Extension") is a Chrome extension for personal use that lets you manage multiple Gmail accounts in a single inbox. Last updated: October 16, 2026.

1. Information accessed and how it is used

The Extension accesses the Gmail API through Google OAuth with the scope https://www.googleapis.com/auth/gmail.modify. It is used solely to read and search emails, manage labels, mark as read/unread, star, archive, delete, reply to, forward and send emails, and show unread counts and notifications. The data is not used for any other purpose.

2. Data storage

Email content, account email addresses, settings and credentials are stored only in your browser (Chrome extension storage). The developer operates no server, and none of this data is sent to, stored on, or shared with the developer or any third party.

Credentials are stored as follows. The access token (valid for about one hour) is kept only in the browser session and is cleared when the browser session ends. The refresh token is kept in the Extension's storage in your browser so that access can be renewed without signing in again. The refresh token is used only to request token renewals from Google's authorization server (oauth2.googleapis.com). If you enter an OAuth client secret in the settings, it is likewise stored only in your browser and used only in requests to Google's authorization server.

3. Communication with external services

The Extension does not communicate with external services except in the following cases.

- The Gmail API (gmail.googleapis.com) and Google's authorization server: to fetch, modify and send email, and to sign in and renew tokens.
- Google Translate (translate.googleapis.com): only if you enable the translation feature and consent, the text of the email you choose to translate is sent to Google Translate. Nothing is sent unless you use translation.
- Images in emails: only if you enable image display, images contained in an email are loaded from the servers the sender specified. Images are not loaded by default.

The Extension does not collect or use data for advertising, tracking, or usage analytics.

4. Sharing with third parties

Data obtained from Google is not sold, shared or transferred to third parties. Humans do not read your email (other than you), and the data is not used for advertising. The Extension's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

5. Data deletion

Removing an account in the Extension asks Google to revoke the Extension's access to that account (if this fails, you can revoke it manually on the permissions page below) and deletes that account's tokens and related data from your browser. Uninstalling the Extension deletes all of its data from your browser. You can also revoke the access you granted at any time on your Google Account permissions page.

6. Changes

If this policy changes, this page will be updated together with the last-updated date.
